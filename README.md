# 黄淮校园生活助手（Campus Life Copilot · 黄淮学院版）

> 面向**黄淮学院**的校园生活助手：考核安排、干饭推荐、记账分析、同学名单、官方入口、校园问答，装进同一个手机界面。
> 后端只用 Python 标准库，前端不引任何外部资源，**双击就能跑、断网也能演示**。

## 一、它解决什么问题

| 校园里的真实痛点 | 助手的做法 |
| --- | --- |
| 考核安排散在教务系统里，单双周、混合式班级记不清 | 「课表」按**当前教学周自动过滤单双周**，标出今天几场、下一场在哪、还有几天 |
| 每天中午的终极难题：吃什么？ | 「干饭」按**当前时段 + 口味偏好 + 单餐预算 + 排队时间**实时打分，给出 TOP3 和推荐理由 |
| 月底才发现钱没了，但不知道花在哪 | 「记账」两次点击记一笔，自动生成**14 天走势图、消费构成、常去地点**和个性化省钱建议 |
| 校园事务（网断了、卡丢了、请假流程）问谁都要等 | 「问答」一句提问秒回，内容来自**本地校园知识库**，可无缝切换大模型 |

## 二、功能演示（5 个标签页 + 登录注册）

```

│  📅 课表      │  🍚 干饭      │  💰 记账      │  👥 同学      │  🤖 问答      │  🏫 黄淮      │
├──────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│ 教学周/班级条 │ 当前时段识别  │ 今日/本月支出 │ 名单增删改查  │ 本地知识库检索│
│ 今日考核+倒计时│ TOP3 推荐     │ 14 天柱状图   │ 学号/联系方式 │ 关键词打分    │
│ 本周网格(单双周)│ 推荐理由     │ 分类/地点排行 │ 身份/备注     │ 常见问题一键问│
│ 全部安排可改删│ 口味/食堂/预算│ 每笔可改删+导出│ 仅本人可见    │ 可清空历史    │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

**登录 / 注册**
- 登录：学号 + 口令（PBKDF2 加盐哈希，Cookie 会话，30 天有效）
- 注册：学号（6—12 位数字）+ 姓名 + 专业 + 口令（≥6 位，两次一致），注册成功自动登录
- 校验：学号格式、重复学号、弱口令、两次口令不一致都会给出明确提示
- 新账号自动带示例考核安排与同学名单，**记账从零开始**

**增删改（三处都能改能删）**
- 考核安排：每条都有「修改 / 删除」，支持「清空全部安排」
- 记账记录：每笔都有「改 / 删」，可导出 CSV、可重置演示账本
- 同学名单：新增、修改、删除，字段含姓名、学号、联系方式、身份、学院、备注
- 问答：可一键清空历史

**账号：** 演示账号 `20230101` / 口令 `123456`（也可以现场注册新账号）

**黄淮学院场景信息（均来自学校官网公开页面，已核对）**
- 学校：黄淮学院，河南省驻马店市开源大道 76 号，邮编 463000；18 个二级学院、61 个在招本科专业、占地 2760 亩
- 校训「厚德、博学、笃行、自强」，校园精神「除了奋斗、别无选择」
- 校园网：教学办公区与宿舍区均已启用**上网实名认证**，连网后打开网页自动跳认证页；账号到校园网服务中心办理，技术问题拨 3728107 / 3728108
- 官方入口：融合服务门户、教务管理系统、校历、网络服务、数字资源、教学资源云平台、云上黄淮等 10 个入口内置在「黄淮」页
- 食堂：南校区（中区）大榕树餐厅（整改后带空调）、北区第一/第二餐厅、西区小吃街、校园超市

**内置演示数据：** 计算机与人工智能学院 · 2025 级 · 计算机科学与技术 · **计科2502B（54 人）**的
考核安排（周一至周五共 24 条记录、12 门课、27 学分，含单双周与混合式班级）+ 14 天消费记录 + 5 人示例名单。

## 三、技术实现

```
campus-life-assistant/
├── start.bat        # Windows 一键启动（优先用随包运行时，自动开浏览器）
├── server.py        # 单文件后端：路由 / 会话 / 注册 / 五个业务模块
├── data_seed.py     # 种子数据：考核安排、22 道菜、11 条校园问答、学生信息
├── runtime/python/  # 随包携带的 Python 3.12 精简运行时（免安装 Python）
├── templates/       # 两个页面：登录/注册页、应用外壳
├── static/          # app.js（原生 JS 单页逻辑）+ style.css（移动优先样式）
├── screenshots/     # 十个页面截图，可直接做比赛封面图
└── data/campus.db   # SQLite，首次启动自动生成
```

- **后端**：Python 3 标准库 `http.server` + `sqlite3`，零第三方依赖；Cookie 会话、PBKDF2 口令哈希、参数化 SQL、**自动列迁移**。
- **前端**：原生 JavaScript 单页应用 + 原生 CSS（无框架、无 CDN），桌面端渲染成手机外壳，移动端全屏。
- **周次引擎**：把「1-16 周」「单周 1-16 周」「双周 1-4 周」「3·7·11·14 周」解析成周次集合，按当前教学周过滤课表，并计算“下一场考核倒计时”。
- **推荐算法**：`时段匹配(±22) + 口味命中(×8) + 食堂偏好(±30) + 预算线性惩罚 + 排队惩罚 + 评分权重`，完全本地计算，毫秒级返回。
- **问答**：关键词加权检索（支持模糊命中与“相近问题”兜底）；设置 `LLM_API_KEY` 后自动切换大模型，失败自动降级，**演示不会翻车**。

## 四、运行方式

### 方式一：不用装 Python（推荐给评委/同学）

直接双击项目根目录的 **`start.bat`**：脚本会自动使用随包携带的 `runtime\python\python.exe`
（Python 3.12 精简运行时，约 36 MB），并自动打开浏览器。**解压后必须保持目录完整**，
`runtime` 文件夹和 `server.py` 要在同一级。

### 方式二：用你自己电脑上的 Python

```bash
# 需要 Python 3.8+，无需安装任何第三方依赖
cd campus-life-assistant
python server.py --port 8866
# 浏览器打开 http://127.0.0.1:8866/
```

> 常见报错：`cd campus-life-assistant` 提示路径不存在，通常是压缩包解压出来的目录名不同
> （例如 `campusLife`），用 `dir` 看一下真实目录名再 `cd`；`python 不是内部或外部命令`
> 说明这台电脑没装 Python，改用方式一即可。

**换成本人的课表 / 班级信息：** 编辑 `data_seed.py` 里的 `STUDENT` 与 `SCHEDULE`，
保存后重启服务会自动重灌课表（老数据库缺失的列会自动迁移，记账与问答历史不受影响）。

可选：接入大模型问答（不配也能完整演示）

```bash
# Windows PowerShell
$env:LLM_API_KEY="你的key"; $env:LLM_BASE_URL="https://api.openai.com/v1"
$env:LLM_MODEL="gpt-4o-mini"; python server.py
```

## 五、亮点与可扩展方向

**亮点**
1. **零依赖、离线可用**：评委电脑上不用装任何环境，拷过去双击 `start.bat` 就能跑；
2. **冷启动即演示**：内置真实感的考核安排与 14 天账本，打开就有数据看；
3. **周次引擎可解释**：单双周、指定周（3·7·11·14 周）都能正确过滤，并直接告诉你“下一场还有几天”；
4. **算法可解释**：每道菜的推荐理由都写明“为什么推荐它”，不是黑盒；
5. **降级设计**：大模型不可用时自动使用本地知识库，演示零风险。

**后续可做**
- 课表从教务系统导入（iCal / 课表截图识别）；
- 考试倒计时加提醒推送（邮件 / 企业微信机器人）；
- 消费数据接入校园卡账单，自动分类；
- 推荐加入“食堂实时人流”（同学众包上报）；
- 团购拼单、室友 AA 记账等社交功能。
