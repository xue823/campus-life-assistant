三、详细说明（整段粘贴）
════════════════════════════════════════════════════════
一、作品简介
面向黄淮学院的校园生活助手，把大学生每天最烦的六件事合并进一个手机界面：查考核安排、
纠结吃什么、钱花哪了、找同学问事、找学校系统入口、问校园事务。支持注册登录与数据增删改，
零第三方依赖、离线可运行，双击 start.bat 即可演示。

二、技术栈
1. 后端：Python 3 标准库（http.server + sqlite3），零第三方依赖；Cookie 会话、
   PBKDF2 加盐口令哈希、参数化 SQL 防注入、老数据库自动列迁移。
2. 前端：原生 JavaScript 单页应用 + 原生 CSS（无框架、无 CDN），桌面端手机外壳、
   移动端全屏自适应。
3. 数据：SQLite 本地库，首次启动自动建表并写入演示数据。
4. 黄淮信息：整合学校官网公开页面（学校简介、上网身份认证通知、快速链接），
   不编造任何未公开数字。

三、功能亮点（六模块）
1. 登录 / 注册：学号 + 口令登录；注册校验学号格式、重复学号、弱口令与两次口令一致性；
   注册成功自动登录并带示例数据；姓名误填成学号时界面显示“同学”，不暴露学号。
2. 考核安排：内置教学周引擎，把「1-16 周」「单周/双周」「3·7·11·14 周」解析成周次集合并
   按当前教学周自动过滤；首屏显示今天几场、下一场在哪、还有几天；每条可修改、可删除、
   可一键清空。数据按《计算机与人工智能学院考核安排表》录入（计科 2502B，24 条记录、
   12 门课、27 学分）。
3. 干饭推荐：覆盖 24 小时的分时段引擎（深夜/早餐/上午加餐/午餐/午间/下午茶/晚餐/晚间加餐/夜宵），
   按「时段匹配 + 口味偏好 + 单餐预算 + 排队时间 + 评分」实时打分，默认输出 TOP6 并给出
   可解释的推荐理由；主品类 +26、次品类 +8、不合适 −18 的三级权重；口味/食堂/预算三维筛选，
   偏好保存到账号。食堂按黄淮实际名称：大榕树餐厅（南区）、北区第一/第二餐厅、西区小吃街、校园超市。
4. 记账分析：两次点击记一笔，自动生成今日/本月支出、14 天走势（超支标橙）、消费构成、
   常去地点 TOP5 与个性化省钱建议；每笔可改可删，支持导出 CSV（带 BOM 防 Excel 乱码）。
5. 同学名单：姓名、学号、联系方式、身份、学院、备注的完整增删改查，数据按账号隔离。
6. 黄淮信息：学校概况（河南省驻马店市开源大道 76 号、18 个二级学院、61 个在招本科专业、
   占地 2760 亩、校训「厚德、博学、笃行、自强」、校园精神「除了奋斗、别无选择」）、
   10 个官方入口一键直达（融合服务门户、教务管理系统、校历、网络服务、数字资源、
   教学资源云平台、云上黄淮等）、联系电话（招生 0396-2853111、党政办 0396-2853503、
   校园网服务中心 3728107/3728108）、校园网实名认证说明。
7. 校园问答：本地知识库 12 条（校园网认证与报修、注册登录、融合服务门户、教务系统、
   校历、图书馆资源、食堂、快递、请假、校医院、奖学金、社团）；配置 LLM_API_KEY 可切换
   大模型，接口异常自动降级本地库，演示零风险。

四、运行方式
方式一（推荐，免安装）：解压后双击 start.bat，自动使用随包 Python 3.12 运行时并打开浏览器。
方式二（自带 Python 3.8+）：python server.py --port 8866
访问地址：http://127.0.0.1:8866/    演示账号：20230101 / 口令：123456
局域网演示：加 --host 0.0.0.0，同 Wi-Fi 设备访问 http://本机IP:8866/

五、工程数据
1. 代码规模：后端 1,000+ 行、前端 600+ 行、样式 350+ 行；
2. 接口 18 个：注册登录、考核安排增删改查、干饭推荐、偏好、记账增删改查、
   同学名单增删改查、黄淮信息、问答与清空、CSV 导出；
3. 数据量：考核安排 24 条 / 12 门课 / 27 学分；菜品 34 道 / 5 个食堂窗口区；
   校园问答 12 条；示例账本 14 天；
4. 冷启动 1 秒内建库并填充；修改 data_seed.py 后重启自动重灌课表（老库自动迁移，
   记账与问答历史保留）。

六、创新点
1. 教学周引擎：单双周 / 指定周自动过滤，把“这周到底上不上”彻底自动化；
2. 24 小时时段引擎：任何时间打开都能得到合规的用餐建议，不会出现“早上显示夜宵”；
3. 推荐可解释：每条推荐都写清理由，不是黑盒排序；
4. 离线优先 + 大模型可选增强的双通道问答，接口异常自动降级，现场演示不会翻车；
5. 零依赖 + 一键启动，任何电脑拷过去双击即可运行，适合现场路演。
